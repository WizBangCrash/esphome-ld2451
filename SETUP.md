# Prerequisites

The following tools etc. are needed to be setup/installed for the repo.

## Pyenv

```bash
brew install pyenv
pyenv local 3.14.7
source .venv/bin/activate
```

## ESPHome

`.venv/bin/pip install -u esphome`

## Clang-Formatter

`.venv/bin/pip install clang-format clang-format==13.0.1`
