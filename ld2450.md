## Component

<span id="ld2451-component"></span>

The `ld2451` component allows you to use the [HLK-LD2451](https://www.hlktech.net/index.php?id=1398) vehicle, motion detection and tracking radar module with ESPHome.

Target tracking involves real-time tracking of the position of a (moving) target within a specific area, enabling
measurement of the target's distance, angle and speed (relative to the sensor). Motionless targets are not reported by the sensor.

The ld2451 is a sensor module for motion target tracking within the Hi-link 24G millimeter-wave radar series. This
module features simplified 24 GHz radar sensor hardware and intelligent algorithm firmware. It's primarily intended
for use outdoors to enable the location tracking of moving vehicles.

[HLK-LD2451 official data sheet and user manuals](https://drive.google.com/drive/folders/1Xl7lnvCAQHD2xjOfU_lpxdr0GGXO0-F6?usp=sharing)

<span id="ld2451-mobile-apps"></span>

[HLKRadarTool Android App](https://play.google.com/store/apps/details?id=com.hlk.hlkradartool)

[HLKRadarTool iOS App](https://apps.apple.com/app/id1638651152)

> [!NOTE]
> Ensure that the ld2451 firmware version is `V1.19.37070120` or later for proper integration functionality. You
> can use the [HLKRadarTool mobile app](#ld2451-mobile-apps) to update the firmware.

The [UART](/components/uart) is required to be set up in your configuration for this sensor to work, `parity` and
`stop_bits` **must be** respectively `NONE` and `1`. Use of hardware a UART is highly recommended in order to
properly support the default 256000 baud rate of the ld2451 module.

```yaml
# ld2451 configuration
ld2451:
  id: ld2451_radar
```

### Configuration variables

- **id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID for this [ld2451](/components/sensor/ld2451/) component.
- **uart_id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID of the [UART Component](/components/uart) to use.
  Required if you have multiple UARTs configured.

## Binary Sensor

The `ld2451` binary sensor offers presence states for the targets.

```yaml
binary_sensor:
  - platform: ld2451
    ld2451_id: ld2451_radar
    has_target:
      name: Presence
    has_approaching_target:
      name: Approaching Target
    targets:
      - approaching:
          name: "Target 1 Approaching"
      - approaching:
          name: "Target 2 Approaching"
      - approaching:
          name: "Target 3 Approaching"
      - approaching:
          name: "Target 4 Approaching"
      - approaching:
          name: "Target 5 Approaching"
```

### Configuration variables

- **ld2451_id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID for the [ld2451](/components/sensor/ld2451/) component.
- **has_target** (*Optional*): True if is detected and moving.
  All options from [Binary Sensor](/components/binary_sensor#config-binary_sensor).

- **has_moving_target** (*Optional*): True if a moving target is detected.
  All options from [Binary Sensor](/components/binary_sensor#config-binary_sensor).

- **targets** (*Optional*): A maximum of 5 targets can be detected.
  - **approaching** (*Optional*): True if target is detected and approaching the sensor.
    All options from [Binary Sensor](/components/binary_sensor#config-binary_sensor).

## Sensor

The `ld2451` sensor provides you with information about the states and attributes of detected targets.

```yaml
sensor:
  - platform: ld2451
    ld2451_id: ld2451_radar
    target_count:
      name: Radar Target Count
    targets:
      - # Target 1
        angle:
          name: "Target 1 Angle"
        distance:
          name: "Target 1 Distance"
        speed:
          name: "Target 1 Speed"

      - # Target 2
        angle:
          name: "Target 2 Angle"
        distance:
          name: "Target 2 Distance"
        speed:
          name: "Target 2 Speed"

      - # Target 3
        angle:
          name: "Target 3 Angle"
        distance:
          name: "Target 3 Distance"
        speed:
          name: "Target 3 Speed"

      - # Target 4
        angle:
          name: "Target 4 Angle"
        distance:
          name: "Target 4 Distance"
        speed:
          name: "Target 4 Speed"

      - # Target 5
        angle:
          name: "Target 5 Angle"
        distance:
          name: "Target 5 Distance"
        speed:
          name: "Target 5 Speed"
```

### Configuration variables

- **ld2451_id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID for the [ld2451](/components/sensor/ld2451/) component.
- **target_count** (*Optional*, int): Total targets detected, whether they are stationary or in motion.
  All options from [Sensor](/components/sensor).

- **targets** (*Optional*): Details about the targets. A maximum of 5 targets can be detected.

  - **angle** (*Optional*, int): Angle of target in `degrees (°)` relative to the `ld2451` sensor.

      All options from [Sensor](/components/sensor).

  - **speed** (*Optional*, int): Speed of the moving target in `km/h`.

      All options from [Sensor](/components/sensor).

  - **distance** (*Optional*, int): Distance in `metres (m)` of the target from the `ld2451` sensor along

> [!NOTE]
> By default, each of the [Sensor](/components/sensor/) components above includes the following
> [filters](/components/sensor#sensor-filters) by default to prevent flooding Home Assistant with state updates:
>
> ```yaml
> - throttle_with_priority: 1000ms
> ```
>
> If you have defined other filters, this default will be overridden; you may of course add it back to your custom
> filter(s) as above if you wish.
>
> To remove the default filters for any given sensor instance, add `filters: []` to its configuration.

## Switch

The `ld2451` switch allows you to control your [ld2451](/components/sensor/ld2451/) `Bluetooth` and `Require Multiple Detections`.

```yaml
switch:
  - platform: ld2451
    ld2451_id: ld2451_radar

    # Require multiple consecutive detections before reporting a target
    # Reduces spurious detections at the cost of latency
    require_multiple_detections:
      name: "Radar Require Multiple Detections"
      id: radar_require_multiple_detections

    # Enable/disable the LD2451 Bluetooth interface
    bluetooth:
      name: "Radar Bluetooth"
      id: radar_bluetooth
```

<span id="ld2451-engineering-mode"></span>

### Configuration variables

- **ld2451_id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID for the [ld2451](/components/sensor/ld2451/) component if you are
  using multiple components.

- **require_multiple_detections** (*Optional*): Turn on/off the Multi Target Detections option. The initial state set based on the
  corresponding setting as read from ld2451 module at boot. All options from [Switch](/components/switch#config-switch).

- **bluetooth** (*Optional*): Turn on/off the bluetooth adapter. Defaults to `true`. All options from
  [Switch](/components/switch#config-switch).

## Number

The `ld2451` number platform allows you to control the maximum detection distance, minimum detection speed, target delay and the signal to noise threshold configuration of your
[ld2451](/components/sensor/ld2451/).

```yaml
number:
  - platform: ld2451
    ld2451_id: ld2451_radar
    max_distance:
      name: "Radar Max Distance"
    min_speed:
      name: "Radar Min Speed"
    no_target_delay:
      name: "Radar No Target Delay"
    snr_threshold:
      name: "Radar SNR Threshold"
```

### Configuration variables

- **ld2451_id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID for the [ld2451](/components/sensor/ld2451/) component.
- **max_distance** (**Required**, int): The maximum distance (range) for detection in metres.
  Any targets detection outside this range will not be reported.
  Set between 1 & 100 in steps of 1. Default is `100`
  All options from [Number](/components/number#config-number).

- **min_speed** (*Optional*): The minimum speed a target must be travelling before being reported in km/h.
  Any targets moving below the minimum speed will not be reported.
  Set between 0 and 120km/h in steps of 1. Default is `0`.
  All options from [Number](/components/number#config-number).

- **no_target_delay** (*Optional*):The delay in seconds before "no target" is reported.

> [!NOTE]
> The `no_target_delay` value applies to *all* the [approaching binary sensor states](#ld2451-binary-sensors) and [target](#ld2451-sensors) states.

- **snr_threshold** (*Optional*): The signl-to-noise ratio (*sensitivity*) [3 -8].
  Higher values reduce false positives but may also miss weak returns.
  Step of 1. Default `3`

## Button

The `ld2451` button allows you to perform `restart`, `factory reset` and `refresh_config` actions on your [ld2451](/components/sensor/ld2451/).

```yaml
button:
  - platform: ld2451
    ld2451_id: ld2451_radar
    factory_reset:
      name: "Radar Factory Reset"
      id: radar_factory_reset
    restart:
      name: "Radar Restart"
      id: radar_restart
    refresh_config:
      name: "Radar Refresh Config"
      id: radar_refresh_config
```

### Configuration variables

- **ld2451_id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID for the [ld2451](/components/sensor/ld2451/) component.
- **factory_reset** (*Optional*): Resets the `ld2451` to its factory default configuration/values.
  All options from [Button](/components/button#config-button).

- **restart** (*Optional*): Restart the `ld2451` device. All options from [Button](/components/button#config-button).

- **refresh_config** (*Optional*): Refresh the configuration of the `ld2451` device.
  Retrieves the internal configuration values from the device and updates the ESPHome entities.
  All options from [Button](/components/button#config-button).

## Select

The `ld2451` select allows you to control `detection_direction` of your [ld2451](/components/sensor/ld2451/).

```yaml
select:
  - platform: ld2451
    ld2451_id: ld2451_radar

    # Detection direction filter
    # Options: "Away" | "Toward" | "All"
    detection_direction:
      name: "Radar Detection Direction"
```

<span id="ld2451-light-function"></span>

### Configuration variables

- **ld2451_id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID for the [ld2451](/components/sensor/ld2451/) component.
- **detection_direction** (*Optional*): Control the direction filter of the device.
  Valid values are `Toward`, `Away` and `All`.
  Setting the value to `Toward` will only report targets moving toward the sensor.
  Setting the value to `Away` will only report targets moving away from the sensor.
  Setting the value to `All` will only report targets moving both toward & away from the sensor.
  Default: `Toward`
  [Select](/components/select#config-select).

## Example configuration

Here is the complete example configuration for [ld2451](/components/sensor/ld2451/).

```yaml
# ============================================================
# ESPHome LD2451 Radar Sensor - Full Example Configuration
# ============================================================
# This example demonstrates all available sensors, binary
# sensors, text sensors, numbers, selects, switches, buttons,
# and automation actions for the ld2451 custom component.
#
# Hardware: ESP32 (or ESP32-C3) connected to HLK-LD2451
# UART wiring: TX (ESP) -> RX (LD2451), RX (ESP) -> TX (LD2451)
# Baud rate: 256000 (fixed, enforced by component)
# ============================================================

esphome:
  name: ld2451-radar
  friendly_name: LD2451 Radar Sensor

esp32:
  board: esp32dev
  framework:
    type: esp-idf

# ── WiFi ────────────────────────────────────────────────────
wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password
  ap:
    ssid: "LD2451 Fallback AP"
    password: !secret ap_password

captive_portal:

# ── Logging ─────────────────────────────────────────────────
logger:
  level: DEBUG

# ── Home Assistant API ───────────────────────────────────────
api:
  encryption:
    key: !secret api_encryption_key

# ── OTA Updates ─────────────────────────────────────────────
ota:
  - platform: esphome
    password: !secret ota_password

# ── External Components ──────────────────────────────────────
# Point to your local checkout or the GitHub repo
external_components:
  - source:
      type: git
      url: https://github.com/WizBangCrash/esphome-ld2451.git
      ref: main
    components: [ld2451]

# ── UART ─────────────────────────────────────────────────────
# Adjust tx_pin / rx_pin to match your wiring
uart:
  id: uart_bus
  tx_pin: GPIO17
  rx_pin: GPIO16
  baud_rate: 256000
  parity: NONE
  stop_bits: 1

# ── LD2451 Hub ───────────────────────────────────────────────
ld2451:
  id: ld2451_radar
  uart_id: uart_bus

# ── Sensors (numeric measurements) ──────────────────────────
sensor:
  - platform: ld2451
    ld2451_id: ld2451_radar

    # Total number of targets currently detected
    target_count:
      name: "Radar Target Count"
      id: radar_target_count

    # Per-target sensors — up to 5 targets supported (index 0–4)
    # Each target exposes: angle (°), distance (m), speed (km/h)
    targets:
      - # Target 1
        angle:
          name: "Target 1 Angle"
          id: target_1_angle
        distance:
          name: "Target 1 Distance"
          id: target_1_distance
        speed:
          name: "Target 1 Speed"
          id: target_1_speed

      - # Target 2
        angle:
          name: "Target 2 Angle"
          id: target_2_angle
        distance:
          name: "Target 2 Distance"
          id: target_2_distance
        speed:
          name: "Target 2 Speed"
          id: target_2_speed

      - # Target 3
        angle:
          name: "Target 3 Angle"
          id: target_3_angle
        distance:
          name: "Target 3 Distance"
          id: target_3_distance
        speed:
          name: "Target 3 Speed"
          id: target_3_speed

      - # Target 4
        angle:
          name: "Target 4 Angle"
          id: target_4_angle
        distance:
          name: "Target 4 Distance"
          id: target_4_distance
        speed:
          name: "Target 4 Speed"
          id: target_4_speed

      - # Target 5
        angle:
          name: "Target 5 Angle"
          id: target_5_angle
        distance:
          name: "Target 5 Distance"
          id: target_5_distance
        speed:
          name: "Target 5 Speed"
          id: target_5_speed

# ── Binary Sensors ───────────────────────────────────────────
binary_sensor:
  - platform: ld2451
    ld2451_id: ld2451_radar

    # True when any target is detected
    has_target:
      name: "Radar Has Target"
      id: radar_has_target
      device_class: occupancy

    # True when any target is moving toward the sensor
    has_approaching_target:
      name: "Radar Has Approaching Target"
      id: radar_has_approaching_target

    # Per-target approaching flag (one entry per target, same order as sensors)
    targets:
      - approaching:
          name: "Target 1 Approaching"
          id: target_1_approaching
      - approaching:
          name: "Target 2 Approaching"
          id: target_2_approaching
      - approaching:
          name: "Target 3 Approaching"
          id: target_3_approaching
      - approaching:
          name: "Target 4 Approaching"
          id: target_4_approaching
      - approaching:
          name: "Target 5 Approaching"
          id: target_5_approaching

# ── Text Sensors ─────────────────────────────────────────────
text_sensor:
  - platform: ld2451
    ld2451_id: ld2451_radar

    # Firmware version reported by the LD2451 module (diagnostic)
    firmware_version:
      name: "Radar Firmware Version"
      id: radar_firmware_version

# ── Numbers (writable configuration parameters) ──────────────
number:
  - platform: ld2451
    ld2451_id: ld2451_radar

    # Maximum detection distance (m) — range: 10–100 m, step: 1
    max_distance:
      name: "Radar Max Distance"
      id: radar_max_distance

    # Minimum speed threshold (km/h) — range: 0–120 km/h, step: 1
    # Targets moving slower than this are ignored
    min_speed:
      name: "Radar Min Speed"
      id: radar_min_speed

    # Delay (seconds) before "no target" state is confirmed — range: 0–255 s, step: 1
    no_target_delay:
      name: "Radar No Target Delay"
      id: radar_no_target_delay

    # Signal-to-noise ratio threshold — range: 3–8, step: 1
    # Higher values reduce false positives but may miss weak returns
    snr_threshold:
      name: "Radar SNR Threshold"
      id: radar_snr_threshold

# ── Select (enum configuration) ──────────────────────────────
select:
  - platform: ld2451
    ld2451_id: ld2451_radar

    # Detection direction filter
    # Options: "Away" | "Toward" | "All"
    detection_direction:
      name: "Radar Detection Direction"
      id: radar_detection_direction

# ── Switches ─────────────────────────────────────────────────
switch:
  - platform: ld2451
    ld2451_id: ld2451_radar

    # Require multiple consecutive detections before reporting a target
    # Reduces spurious detections at the cost of latency
    require_multiple_detections:
      name: "Radar Require Multiple Detections"
      id: radar_require_multiple_detections

    # Enable/disable the LD2451 Bluetooth interface
    bluetooth:
      name: "Radar Bluetooth"
      id: radar_bluetooth

# ── Buttons ──────────────────────────────────────────────────
button:
  - platform: ld2451
    ld2451_id: ld2451_radar

    # Restore all sensor parameters to factory defaults
    factory_reset:
      name: "Radar Factory Reset"
      id: radar_factory_reset

    # Restart (reboot) the LD2451 module
    restart:
      name: "Radar Restart"
      id: radar_restart

    # Re-read current configuration from the module and update HA entities
    refresh_config:
      name: "Radar Refresh Config"
      id: radar_refresh_config

# ── Example Automations ──────────────────────────────────────
# The component also exposes three automation actions:
#   ld2451.factory_reset   — same as the button above
#   ld2451.restart         — same as the button above
#   ld2451.refresh_config  — same as the button above
#
# Example: refresh config on boot so HA shows current values
interval:
  - interval: 1s
    then:
      - if:
          condition:
            - binary_sensor.is_on: radar_has_approaching_target
          then:
            - logger.log: "Approaching target detected!"

# Boot-time config refresh using the automation action
esphome:
  on_boot:
    priority: -100
    then:
      - ld2451.refresh_config: ld2451_radar
```
